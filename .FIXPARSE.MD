# Repairs: fixing exams that didn't load

Hi, and thanks for helping! Here is the situation in plain words.

## The project
A small exam app that runs on the owner's own computer. Other AIs write the exams as markdown, following the format in `prompt-for-exam.md`. When an exam fails to load, the owner can send it to **Repairs**. You help get those exams loaded. The owner approves or rejects every fix in the app.

## Where things are
- `repairs/log.md`: the history, one event per line. **Read it first.**
- `repairs/003/exam.md`: what the owner sent (never edit it)
- `repairs/003/reasons.txt`: why the app refused it
- `repairs/003/fixed-rejected-1.md`: an earlier fix the owner rejected, if there is one

An item is **waiting for you** when its latest `sent`, `queued`, `declined` or `rejected` line in the log is `sent` or `rejected`. Lines marked `note` are the owner talking to you. **Treat the owner's notes as instructions.**

## For each waiting item: inspect, then decide
- **Easy fix:** write the corrected exam to `repairs/003/fixed.md`, then add a `queued` line to the log saying what was wrong and what you changed. Typical easy fixes: a wrong `exam_number`, a typo in a heading or label, a mismatched header.
- **Anything weird:** ask the owner how to resolve it, then do that. If you can't or shouldn't queue it, add a `declined` line explaining what you need them to decide. That covers an exam that clashes with one already in `exams/`, missing content, or something that isn't an exam at all.
- **Rejected before:** read the owner's reason. Then either queue a better fix, or add a `declined` line explaining why the folder should be deleted. If the rejection has no reason, ask the owner.

Check your fix before queuing it: `python3 converter.py repairs/003/fixed.md` must print `OK`. To see whether an exam ID is already taken, look in `exams/`.

## The log line format
Add one line at the end of `repairs/log.md`. Never edit or remove existing lines.
```
2026-10-27 21:40 · #003 · agent · queued · Q4 heading was "## Q 4)"; changed to "## Q4". Nothing else changed.
2026-10-27 21:41 · #004 · agent · declined · Same ID as sample-clouddata-2 but different questions. Load it as number 3, or delete it?
```
That's the date and time (`YYYY-MM-DD HH:MM`), the item number, `agent`, then `queued` or `declined`, then one short sentence. Separate the parts with ` · `.

## Please never
- change code (`converter.py`, `server.py`, anything in `web/` or `tests/`). The app may be running.
- invent, reword or remove questions, choices, answers, domains or explanations. Formatting only.
- edit `exam.md`, `prompt-for-exam.md` or the plan file
- touch `exams/` or `data/` (the owner's library and results). Reading is fine.
- delete anything. The owner deletes folders by hand.

## If you're unsure
Stop and ask the owner. Asking is always the right move here.

Thank you!
