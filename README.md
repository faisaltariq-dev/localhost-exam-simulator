# Localhost Exam Simulator

Practice certification exams locally, under real exam conditions: 4-option questions, bookmarks, a review list, notes, a countdown that turns into red overtime, and a score breakdown by exam domain. Exams are generated by any AI chat from a fixed format and dropped into the page.

Python 3.9+ standard library only. No installs, no build step, works offline.

## Run

```
python3 server.py            # then open http://localhost:8000
python3 server.py --port 9000
```

## Workflow

1. Open the library and copy the **prompt-for-exam.md** block.
2. Ask any AI for an exam, e.g. *"GCP ADP, extra difficult, at least one very close distractor per question. Follow this prompt-for-exam.md for the exact output file structure."*, and paste the prompt.
3. Save the reply as `questions-and-answers-<maker>-<exam>-<n>.md`.
4. Drag it onto the drop zone. It's validated and saved, or rejected with every problem listed. Duplicate names are never overwritten.
5. Pick the exam and take it. Results show your score by domain, the explanations, and your notes.

Try it first with `samples/questions-and-answers-sample-demo-1.md`.

## Files

| Path | What it is |
|---|---|
| `reproduciable-plan-prompt-for-localhostexamsimulatorparser.md` | The full design. Frozen, so you can hand it to another agent to build a variant. |
| `prompt-for-exam.md` | The output format you give to the exam-writing AI. |
| `converter.py` | Parses and validates exam markdown. `python3 converter.py <file>` checks a file without importing it. |
| `store.py` | Storage, scoring, domain scores, the green-tally rule. |
| `server.py` | Local HTTP server and JSON API (127.0.0.1 only). |
| `web/` | The single-page app (`js/library.js`, `exam.js`, `results.js`, `settings.js`). |
| `exams/`, `data/` | Your imported exams, attempts and settings (not tracked by git). |

```
python3 -m unittest discover tests
```

## Git

The history is one commit per module, in build order, so it can be replayed (`git log --reverse`) and parts redesigned independently. Keep to that: one concern per commit, tests green, no history rewrites.
